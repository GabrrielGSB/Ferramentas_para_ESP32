# Componente WS2812 / WS2812B (Neopixel)

Classe em C++ para controle de LEDs RGB endereçáveis **WS2812 / WS2812B** no ESP32, utilizando o periférico de hardware **RMT (Remote Control)** com temporizações precisas de 800 kHz.

---

## 🚀 Recursos

- **Hardware RMT Dedicado:** Transmissão precisa dos pulsos sem atrasos causados por interrupções ou bloqueio de CPU.
- **Suporte a Fitas e LEDs Unitários:** Configuração flexível de 1 até centenas de LEDs em série.
- **Gerenciamento de Cores:**
  - Struct `CorRGB` com suporte a cores pré-definidas (`Vermelho`, `Verde`, `Azul`, `Branco`, `Amarelo`, etc.).
  - Conversão de espaço de cor **HSV para RGB** para transições e efeitos suaves (`CorRGB::deHSV`).
- **Controle de Brilho Global:** Ajuste de intensidade de 0 a 255 sem alterar a paleta armazenada no buffer.
- **RAII e Segurança:** Destrutor desliga os LEDs e libera automaticamente os canais de hardware RMT.
- **Compatível com o ecossistema:** Totalmente utilizável com o componente [Task]

## 📋 API da Classe

### Struct `CorRGB`
```cpp
struct CorRGB {
    uint8_t r, g, b;
    CorRGB(uint8_t vermelho, uint8_t verde, uint8_t azul);
    static CorRGB deHSV(uint16_t h, float s, float v);

    // Cores estáticas prontas:
    static const CorRGB Preto, Branco, Vermelho, Verde, Azul, 
                         Amarelo, Ciano, Magenta, Laranja, Roxo;
};
```

### Métodos Principais de `WS2812`

| Método | Descrição |
|---|---|
| `WS2812(gpio_num_t pino, uint16_t numLeds = 1, uint8_t brilho = 255)` | Construtor configurando pino DIN, quantidade e brilho inicial |
| `esp_err_t inicializar()` | Configura e habilita o canal transmissor RMT |
| `void definirCor(uint16_t index, uint8_t r, uint8_t g, uint8_t b)` | Define a cor de um LED específico |
| `void definirCor(uint16_t index, const CorRGB& cor)` | Define a cor de um LED específico usando `CorRGB` |
| `void definirTodos(const CorRGB& cor)` | Define a mesma cor para todos os LEDs |
| `void limpar()` | Apaga todos os LEDs no buffer interno |
| `void setBrilho(uint8_t brilho)` | Ajusta o brilho global (0 a 255) |
| `esp_err_t atualizar(uint32_t timeoutMs = 1000)` | Envia fisicamente o buffer para os LEDs |
| `void efeitoArcoIris(uint16_t deslocamentoMatiz = 0)` | Gera gradiente arco-íris automático |

## 🛠️ Exemplos de Uso

### 1. LED Unitário (Ex: LED RGB de placa de desenvolvimento)

```cpp
#include "WS2812.hpp"
#include "Tempo.hpp"

extern "C" void app_main(void) {
    // LED conectado ao GPIO 8 (comum em placas ESP32-C3 / S3)
    WS2812 led(GPIO_NUM_8, 1);
    led.inicializar();
    led.setBrilho(50); // 20% do brilho para não ofuscar

    while (true) {
        led.definirTodos(CorRGB::Vermelho);
        led.atualizar();
        delay_ms(500);

        led.definirTodos(CorRGB::Verde);
        led.atualizar();
        delay_ms(500);

        led.definirTodos(CorRGB::Azul);
        led.atualizar();
        delay_ms(500);
    }
}
```

### 2. Fita de LEDs com Efeito Arco-Íris contínuo

```cpp
#include "WS2812.hpp"
#include "Tempo.hpp"

extern "C" void app_main(void) {
    // Fita com 30 LEDs no GPIO 18
    WS2812 fita(GPIO_NUM_18, 30, 80);
    fita.inicializar();

    uint16_t matiz = 0;
    while (true) {
        fita.efeitoArcoIris(matiz);
        fita.atualizar();

        matiz = (matiz + 2) % 360;
        delay_ms(20);
    }
}
```

### 3. Integração com a classe `Task` (FreeRTOS)

```cpp
#include "WS2812.hpp"
#include "Task.hpp"
#include "Tempo.hpp"

// Instância global ou de classe
WS2812 fitaStatus(GPIO_NUM_18, 8, 100);

void loopAnimacaoStatus() {
    uint16_t matiz = 0;
    while (true) {
        fitaStatus.efeitoArcoIris(matiz);
        fitaStatus.atualizar();
        matiz = (matiz + 5) % 360;
        delay_ms(30);
    }
}

extern "C" void app_main(void) {
    fitaStatus.inicializar();

    // Cria e inicia uma tarefa dedicada no Core 1 para a animação
    Task taskLed(loopAnimacaoStatus, "TaskLED", 4096, 1, TaskCore::Core1);
    taskLed.iniciar();
}
```
